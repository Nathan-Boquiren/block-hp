<h1 align="center">Block.HP — 3D Printing Services Landing Page</h1>

Welcome to the official landing page for **Block.HP**!  
We specialize in creating custom 3D printed **keychains, toys, cosplay props, decorations, replacement parts,** and **art displays**.

This project is a simple, lightweight website built using plain **HTML**, **CSS**, and **JavaScript**, designed to showcase our work and provide contact information for orders and inquiries.

## Live Preview

👉 [Visit the site here](https://nathan-boquiren.github.io/block-hp/)

## Features

- **Gallery** of our 3D printed products
- **Contact Information** for custom orders and questions
- Fast-loading, mobile-friendly design
- Built with vanilla HTML/CSS/JavaScript (no frameworks)

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
